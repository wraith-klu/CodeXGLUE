# CodeXGLUE Clone Detection Benchmark Dataset

This directory links to Microsoft Research's CodeXGLUE Code-Code Clone Detection benchmarks:
- **BigCloneBench**: Java semantic code clone detection (`../Clone-detection-BigCloneBench/`)
- **POJ-104**: C/C++ algorithmic problem clone detection (`../Clone-detection-POJ-104/`)

Used to fine-tune **Model 2: CodeBERT Siamese Twin Clone Detector**.
